# PRODIGY_WD_02 – Stopwatch Web Application

A modern and interactive stopwatch web application developed as part of my **Web Development Internship at Prodigy Infotech**.

## 🚀 Features

- Start, Pause, and Reset stopwatch
- Record and display lap times
- Best lap time calculation
- Average lap time calculation
- Total lap counter
- Keyboard shortcuts
  - `Space` – Start/Pause
  - `L` – Record Lap
  - `R` – Reset
- Responsive design for desktop and mobile
- Modern dark-themed user interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Font Awesome
- Google Fonts
